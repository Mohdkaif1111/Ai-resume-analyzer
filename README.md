An AI-powered Resume Analyzer built using HTML, CSS, and JavaScript. It reads and parses resume content, extracts essential information, identifies matching skills, and provides ATS-friendly suggestions to help users improve their resumes.

# 🚀 Features
📂 Upload resume files (PDF/DOCX/Text)
📖 Parse and extract resume text
👤 Detect basic information (Name, Email, Phone)
💼 Identify technical skills
📊 Calculate a resume score
✅ Show matched skills
💡 Provide ATS-friendly improvement suggestions
⚡ Fast processing directly in the browser
🎨 Clean and responsive user interface

# 🛠️ Tech Stack
HTML5
CSS3
JavaScript (Vanilla JS)
PDF.js (PDF Parsing)
Mammoth.js (DOCX Parsing)

AI-Resume-Analyzer/

# ⚙️ How It Works
Upload your resume.
The application extracts the text from the file.
JavaScript parses the resume content.
Important details like contact information and skills are detected.
The analyzer compares detected skills and calculates a resume score.
Suggestions are generated to improve ATS compatibility.
